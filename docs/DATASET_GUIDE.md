# Data provenance and dictionary

## Provenance

`data/hospitals.csv` is generated locally by `data/generate_dataset.py`. It is not downloaded from hospitals, government portals, insurers, review sites, or a verified medical dataset. The generator uses fixed city-centre reference coordinates and random offsets to create illustrative map points. Names use `Demo Hospital Hxxxx` identifiers so the records do not imply a real provider relationship.

The following values are generated, not observed:

- procedure costs and tier multipliers;
- star ratings, review counts, and review text;
- bed counts and accreditation flags;
- sample insurance tags;
- latitude/longitude offsets;
- sentiment values derived from generated review snippets.

The dataset is reproducible from a fixed random seed, but it is not a sample of actual hospital operations. It must never be described as verified or current Indian hospital data.

## Field dictionary

| Field | Meaning in this demo | Important limitation |
|---|---|---|
| `hospital_id` | Stable synthetic record identifier | Not a real provider ID |
| `name` | `Demo Hospital` plus record ID | Not a real hospital name |
| `city`, `state` | City and state labels used to group generated records | Not a facility address |
| `primary_specialty` | Generated specialty category | Not a verified service offering |
| `primary_procedure` | Representative procedure associated with the generated specialty | Not a provider's actual procedure catalogue |
| `tier` | Generated Premium / Mid-Range / Budget category | Not a market classification |
| `avg_cost_for_procedure` | Simulated INR target value | Not a quotation or observed average |
| `avg_rating` | Generated numeric rating | Not a real rating |
| `num_reviews` | Generated review-count value | Not an actual count |
| `sentiment_score` | Independently generated numeric demo feature used by CES and the cost model | Not calculated from real reviews or patient sentiment evidence |
| `bed_count` | Generated capacity-like value | Not verified capacity |
| `latitude`, `longitude` | Random offsets around city centres | Not hospital coordinates |
| `accredited` | Generated boolean flag for UI filtering | Not NABH/JCI or any other accreditation |
| `insurance_accepted` | Placeholder tags such as `Sample Insurance A` | Not insurer acceptance or coverage |
| `reviews` | Pipe-separated generated example text; per-snippet sentiment is calculated at display time | Not patient reviews or testimonials |

## Cost-model target and evaluation

The experimental model predicts `avg_cost_for_procedure` using `bed_count`, `avg_rating`, `num_reviews`, `sentiment_score`, `city`, `primary_specialty`, and `tier`. Its training/evaluation labels are generated by the same script. Holdout and cross-validation metrics therefore measure fit to the synthetic data-generation process only. They do not establish performance on real hospitals, real prices, or unseen real-world conditions.

## Reproducibility

```bash
python data/generate_dataset.py
python ml/cost_model.py
```

The generator seeds Python's `random` and NumPy's random number generator with `42`.
